# Chaîne de données boursières

Projet du cours Python pour le Big Data (EPITA, spécialisation SCIA, 2026).

- ETL Python : lecture de fichiers hétérogènes (CSV, classeurs Excel, archives bz2), nettoyage des valeurs, harmonisation des colonnes entre sources, dates tirées des noms de fichiers, lecture parallèle par lots.
- Stockage dans TimescaleDB, agrégats journaliers.
- Tableau de bord Dash et Plotly : courbes, chandeliers, bandes de Bollinger, volumes.
- Déploiement avec Docker Compose (`pybd_given_code/compose.yml`).
